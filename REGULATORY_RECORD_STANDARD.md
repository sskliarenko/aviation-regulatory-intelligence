# Regulatory Record Standard

Every substantive regulatory intelligence record should include:

    Source:
    Source type: Regulation / AMC / GM / OSD / ED Decision / Guidance / Other
    Provision / reference:
    Publication date:
    Effective date:
    Last verified:
    Status: Current / Amended / Superseded / Withdrawn
    Superseded by:
    Applicability:
    Interpretation owner:
    Notes:

## Rules
- Verify against the primary source whenever practical.
- Do not rely on an undated summary for current compliance work.
- Distinguish binding regulation from AMC, GM, OSD, guidance and interpretation.
- Record the last verification date.
- If superseded, retain traceability to the replacement.
- Interpretations must be labelled as interpretations, not regulatory text.
